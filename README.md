# 💰 GastoCerto v2.0

Controle financeiro pessoal completo.

## Integrante
- Luis Antonio Santos Moura

## Tecnologias
- React Native + Expo SDK 54
- TypeScript · SQLite · @expo/vector-icons

## Funcionalidades
- ✅ Lançamentos de despesas e receitas
- ✅ Despesas fixas (repete 24 meses)
- ✅ Despesas parceladas (N parcelas)
- ✅ Marcar lançamento como pago
- ✅ Dashboard com saldo = receitas - despesas
- ✅ Extrato com filtros e agrupamento por data
- ✅ Gráficos por categoria
- ✅ Gerenciar categorias de despesas e receitas

## Como executar
```bash
npm install
npx expo start
```
